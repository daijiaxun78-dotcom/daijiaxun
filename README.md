# 中国 QDII 标普 / 纳指场外基金限额跟进

首版范围仅包含：标准标普500、标普500等权重、标准纳斯达克100。工具使用 Python 标准库和 SQLite，不需要安装第三方包。

## 启动

```powershell
python server.py
```

## 免费云端发布

静态站点位于 `static/`，`export_static.py` 将 SQLite 数据导出为
`static/data.json`。网页只读展示该快照，成本比较在浏览器本地计算。

```powershell
python export_static.py --refresh
```

`.github/workflows/update-data.yml` 在工作日自动刷新并提交数据快照；
Cloudflare Workers Static Assets 监测默认分支后自动发布到固定的
`*.workers.dev` 地址。上游更新失败时，导出过程保留已有有效净值字段。

如果系统没有配置 Python，可使用 Codex 工作区随附的 Python 运行 `server.py`。启动后访问 <http://127.0.0.1:8765>。

首次进入页面后点击“更新正式净值”。程序从公开净值接口拉取上一年末至今的数据，并在本地计算今年以来收益。

页面首次打开即包含截至 2026-08-11 的公开数据快照，包括 YTD、合并规模、综合费率和申购状态。快照数据在界面标为“公开快照”；成功更新正式净值后，YTD 会切换为“正式净值计算”。精确限额只有附基金公司公告的记录才显示“官方核验”。

## 数据原则

- 一行对应一个基金份额代码，A/C/D/I 类不合并。
- YTD 使用上一年度最后一条累计净值到最新正式累计净值计算。
- 精确限额按基金代码、渠道、业务类型和生效区间保存。
- 聚合接口的申购状态仅作为线索，精确限额必须附官方公告链接。
- “份额成本比较”可输入金额、持有天数和 A/C 类实际费率；管理费等年费与另行支付费用分开显示。
- `funds.db` 是本地数据文件，首次启动自动创建。

## 当前边界

- 基金清单为首批人民币场外份额，需要持续对照产品资料概要补充。
- 净值已自动化；规模、完整费率档位和各基金公司公告解析器仍需逐步接入。
- 当前登记限额功能用于经人工核对的官方公告，避免错误自动匹配造成误导。
